03 / PHASE BREAKDOWN

Phase Details

// 每个阶段的具体功能与技术实现

PHASE 01

Keyword Monitor

  • Cloudflare Worker 定时调用 GSC API
  • 50+ 目标关键词排名追踪
  • 展示次数 / 点击次数 / 平均排名
  • 历史趋势存储于 Cloudflare KV
  • Admin 后台可视化排名曲线
  • 按产品线分组展示
GSC API + KV
PHASE 02

Opportunity Engine

  • 高展示 + 低点击 → 标题/Meta 优化建议
  • 排名 11-20 → 新博客助推到 Top 10
  • 有展示 + 无排名 → 全新长尾词机会
  • 竞品关键词差距分析
  • 每周自动生成选题清单
  • 按搜索意图分类（导航/信息/交易）
AI Analysis + GSC Data
PHASE 03

Content Generation

  • LLM 生成大纲 → 正文 → HTML
  • 2000-3000 字深度技术文章
  • 含参数表 / 对比数据 / 案例引用
  • 自动插入内部链接到产品页
  • FAQ 段落自动生成 FAQPage Schema
  • Article Schema + Breadcrumb Schema
LLM API + HTML Template
PHASE 04 — NEW

AI Image Generation

  • 根据文章标题自动构建图片 Prompt
  • Hero 大图 1280×720px（工业场景）
  • 内容配图 800×600px ×2-4 张（产品/应用）
  • 自动压缩为 WebP 格式
  • 文件名含目标关键词（SEO 友好）
  • alt 属性自动生成
SDXL / DALL-E API + Sharp
PHASE 05

SEO Quality Scoring

  • Title 含关键词（前 60 字符）
  • Meta description 150 字含关键词
  • H1/H2/H3 层级检查
  • 关键词密度 1-2%
  • 内链数量 ≥ 3 条
  • 图片 alt + Schema 校验
  • 评分 < 80 → AI 自动修改循环
Custom Auditor + LLM Fix
PHASE 06

Deploy & Index

  • 人工审核内容 + 图片质量
  • Git push → Cloudflare Pages 自动部署
  • 自动更新 sitemap.xml
  • GSC 主动请求编入索引
  • 自动提交到 Bing Webmaster
  • 社交媒体自动发布（可选）
GitHub API + GSC Indexing API
PHASE 07

Performance Tracking

  • 新文章 GSC 排名追踪（7/14/30 天）
  • GA4 页面浏览量 / 跳出率
  • AI Referral 流量监控
  • Umami 实时访客数据
  • 排名数据回流到 Phase 01
  • 每月生成 SEO 效果报告
GA4 + GSC + Umami
INFRA

Cloudflare Worker

  • Cron Triggers 定时执行
  • KV 存储排名/选题/评分历史
  • R2 存放生成的图片
  • 代理 GSC API（CORS 解决方案）
  • 代理 AI API（内容生成 + 图片生成）
  • Admin SPA 后台 API
Workers + KV + R2
IMG TECH

Image Tech Stack

  • AI 生成 API（SDXL / DALL-E）
  • Sharp 图片压缩优化
  • WebP 格式输出
  • Prompt 模板按产品线预设
  • 文件命名规则：{keyword}-{type}.webp
  • 自动上传到 R2 + 本地 images/blog/
AI Gen API + Sharp + R2
04 / COMPARISON

Our Workflow vs Generic WP Flow

// 相比图中 WordPress 工作流的改进点

维度 通用 WP 方案 我们的方案 改进
CMS 依赖 WordPress + Rank Math Cloudflare Worker + 自建评分器 无 CMS 依赖
关键词数据源 Google Sheets 手动输入 GSC API 自动拉取真实数据 数据驱动
内容质量 AI 生成直接发布 AI 生成 + 评分 + 人工审核 质量保障
图片制作 手动找图/无图片 AI 自动生成 Hero + 配图 全自动配图
发布频率 日更多篇（水文） 每周 1-2 篇深度技术文 重质不重量
排名追踪 无反馈闭环 排名数据回流优化选题 闭环反馈
SEO 评分 Rank Math 插件 自建 30+ 项检查 + AI 自动修复 可定制
部署方式 WP 数据库 Git Push → Cloudflare Pages 静态 CDN 部署
AI 引擎优化 无 GEO 能力 已有 llms.txt + AI 爬虫放行 SEO + GEO 双优化
