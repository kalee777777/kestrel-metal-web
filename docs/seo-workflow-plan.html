SETUP 01

Google Cloud Service Account

用于访问 Google Search Console API，拉取关键词排名数据

  • 进入 Google Cloud Console → 创建新项目
  • 启用 Search Console API
  • 创建 Service Account → 生成 JSON 密钥
  • 在 GSC 中将此 Service Account 邮箱添加为网站用户（只读权限）
  • 下载 JSON 密钥文件，提供给我配置到 Worker secrets
需要你操作
SETUP 02

DeepSeek API Key

用于 AI 内容生成 — 大纲、正文、SEO 修复

  • 注册/登录 DeepSeek 平台
  • 进入 API Keys 页面 → 创建新 Key
  • 复制 API Key 提供给我配置到 Worker secrets
  • 确认 V4 Pro 模型名称和 API endpoint
需要你操作
SETUP 03

GitHub Personal Access Token

用于自动提交新博客 HTML 文件到仓库，触发 Cloudflare Pages 部署

  • GitHub Settings → Developer settings → Personal access tokens
  • 创建 Fine-grained token，权限：Contents (Read/Write) 仅限目标仓库
  • 复制 token 提供给我配置到 Worker secrets
需要你操作

AI Image Generation API

用于自动生成博客文章配图 — Hero 图 + 内容配图

Write a detailed article outline for the keyword: {{keyword}} Requirements: - H1: compelling title containing the exact keyword (max 60 chars) - 4-6 H2 sections covering: introduction, technical specs, applications, buying guide, FAQ - Each H2 should have 2-3 H3 sub-sections - Include a FAQ section with 5 common questions - Target: 2000-3000 words total - Tone: professional B2B, data-driven, authoritative Output format: JSON { "title": "...", "meta_description": "...(150 chars)...", "sections": [{ "h2": "...", "h3": ["...", "..."], "key_points": ["..."] }], "faq": [{ "q": "...", "a": "..." }] }

Write the full article body based on this outline: {{outline_json}} Rules: - Write in professional English for B2B audience - Include technical parameters and specifications where relevant - Use bullet points and numbered lists for readability - Reference real-world applications (construction, agriculture, security) - Insert {{internal_link}} placeholders where internal links to product pages should go - Do NOT include h1/h2/h3 tags — I will inject them from the outline - Output: plain text with paragraph breaks, I will handle HTML wrapping

SEO Scoring & Auto-Fix

30+ 项 SEO 检查 + 低于 80 分 AI 自动修复循环
TODO
  • 创建 src/lib/auditor.ts — SEO 质量评分器
  • 检查项：Title 含关键词且 ≤ 60 字符 (10分)
  • 检查项：Meta Description 含关键词且 120-160 字符 (10分)
  • 检查项：H1 唯一且含关键词 (5分)
  • 检查项：H2-H3 层级正确无跳级 (5分)
  • 检查项：关键词密度 1-2% (10分)
  • 检查项：内部链接 ≥ 3 条 (10分)
  • 检查项：所有图片有 alt 属性含关键词 (10分)
  • 检查项：Article + FAQPage + Breadcrumb Schema 完整 (10分)
  • 检查项：首段前 100 字含核心定义 (5分)
  • 检查项：字数 ≥ 1500 字 (5分)
  • 检查项：段落长度 ≤ 150 字 (5分)
  • 检查项：canonical URL 正确 (5分)
  • 检查项：Open Graph + Twitter Card 标签 (5分)
  • 检查项：图片文件名含关键词 (5分)
  • 实现 Auto-Fix：评分 < 80 → DeepSeek 修复缺陷 → 重新评分（最多 3 轮）
  • 3 轮后仍 < 80 → 标记 SKIPPED，记录日志，跳过发布
  • 创建 src/cron/score.ts — 每周一 05:00 图片生成后执行
