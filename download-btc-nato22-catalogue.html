NATO-22 Blade Profile Specification

NATO-22 is the high-security BTC blade profile supplied for military perimeters, borders, airports, prisons, substations and solar farm perimeters. It is compatible with Kestrel 3D panel and 358 anti-climb fence systems (Y-post mounted).

Note: NATO-22 is a blade profile designation; ASTM F1910 is a separate formal specification for long barbed tape obstacles. The two are not interchangeable, and buyers specifying NATO-22 should request blade profile verification rather than generic ASTM statements.
